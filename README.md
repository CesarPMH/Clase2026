# Punto Cero

Sistema web para panaderías y pastelerías que trabajan **por encargo**: registra pedidos paso a paso (con configurador de pasteles personalizados), les da seguimiento en calendario y gestión, controla pagos y gestiona cambios mediante solicitudes con aprobación e historial.

Proyecto universitario — materia de Programación.

## Qué incluye
- **Nuevo pedido en 4 pasos:** cliente, entrega, pedido y pago.
- **Configurador de pasteles personalizados**, cupcakes y galletas, con cálculo de precio y reglas del negocio.
- **Registro, gestión y calendario de pedidos.**
- **Cambios controlados:** al editar un pedido se ve su historial y se envía una solicitud que se aprueba o se rechaza.

## Tecnologías
React · Vite · Material UI · React Router

## Ejecutar en local
```bash
npm install
npm run dev
```

> Prototipo de front-end con datos de demostración guardados en el navegador (sin backend).
